    Health computation logic (per D-04/D-05/D-06):
    - Use window function `row_number() OVER (PARTITION BY retailer_url_id ORDER BY scraped_at DESC)` to get last 10 attempts per URL.
    - Aggregate: success_count = SUM(is_success), window_size = COUNT(*).
    - Status: success_rate = success_count / window_size. If >= 0.8 then "healthy", if >= 0.5 then "degraded", else "failing".
    - Consecutive failures: count attempts from most recent backwards until a success is found. Use a subquery that finds the `scraped_at` of the most recent success within the last 10, then count failures after it. If no successes in window, consecutive = window_size.
    - last_success_at: MAX(scraped_at) WHERE is_success=True across ALL attempts (not just window).
    - last_error_type: error_type from the most recent attempt WHERE is_success=False.
    - Domain extraction: done in Python via `urllib.parse.urlparse(url).hostname` after query.
    - Join RetailerUrl and WatchQuery to get url and watch_query name.
