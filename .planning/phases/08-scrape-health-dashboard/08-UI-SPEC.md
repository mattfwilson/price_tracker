## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, gap between mini-dot and domain label |
| sm | 8px | Compact element spacing, table cell vertical padding |
| md | 16px | Default element spacing, table cell horizontal padding |
| lg | 24px | Section padding, page content padding |
| xl | 32px | Layout gaps between page header and table |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (not used in this phase) |

Exceptions: Mini-dots use `h-2 w-2` (8px) to match existing StatusDot scale. Gap between mini-dot and domain label is `gap-1.5` (6px) to match existing StatusDot inner gap.

## Typography

| Role | Size | Weight | Line Height | Font Family |
|------|------|--------|-------------|-------------|
| Body | 14px | 400 (regular) | 1.5 | DM Sans |
| Label | 12px | 400 (regular) | 1.5 | DM Sans |
| Heading | 24px | 700 (bold) | 1.2 | Outfit |
| Table Header | 14px | 500 (medium) | 1.5 | DM Sans |

Usage in this phase:
- **Heading (24px Outfit bold):** Page title "Scrape Health" -- matches existing `text-2xl font-heading font-bold` pattern from DashboardPage and AlertsPage
- **Body (14px DM Sans regular):** Table cell content (domain, query name, success rate, error type, timestamps)
- **Label (12px DM Sans regular):** Mini-dot domain labels on QueryCard, filter labels above health table, tooltip text
- **Table Header (14px DM Sans medium):** Column headers in health table -- matches existing shadcn Table component defaults

### Health Status Colors (semantic, phase-specific)

These reuse the exact Tailwind classes already established in `StatusDot.tsx`:

| Status | Dot Class | Foreground Class | Meaning |
|--------|-----------|-----------------|---------|
| Healthy | `bg-emerald-500` | `text-emerald-500` | >= 80% success rate (8+ of last 10) |
| Degraded | `bg-amber-500` | `text-amber-500` | 50-79% success rate |
| Failing | `bg-red-500` | `text-red-500` | < 50% success rate |

These colors are NOT accent -- they are semantic status indicators, consistent with the existing StatusDot palette.

## Layout Specifications

### Health Page (`/health`)

```
+----------------------------------------------------------+
| Price Scraper            Health   [ThemeToggle] [Bell]    |  <- Header with nav link
+----------------------------------------------------------+
|                                                          |
|  Scrape Health                                           |  <- h1, 24px Outfit bold
|                                                          |
|  [All] [Degraded & Failing]                              |  <- Filter bar
|                                                          |
|  +------------------------------------------------------+|
|  | Status | URL       | Query   | Rate  | Last OK | Fails | Error  ||  <- Table header
|  |--------|-----------|---------|-------|---------|-------|--------||
|  | (dot)  | amazon..  | Query 1 | 8/10  | 2h ago  |   0   | --     ||
|  | (dot)  | bestbuy.. | Query 1 | 6/10  | 1d ago  |   2   | blocked||
|  | (dot)  | walmart.. | Query 2 | 3/10  | 5d ago  |   5   | timeout||
|  +------------------------------------------------------+|
|                                                          |
+----------------------------------------------------------+
```

- Page uses `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8` (matches existing Layout component)
- Table is full-width within the content area
- Filter bar has `mb-4` gap above table
- Page title has `mb-6` gap below (matches DashboardPage and AlertsPage)

### Health Table Columns

| Column | Width | Content | Sortable |
|--------|-------|---------|----------|
| Status | `w-10` | HealthStatusDot (dot only, no label) | Yes (failing > degraded > healthy) |
| URL | auto | Domain extracted from URL (e.g., "amazon.com") | No |
| Watch Query | auto | Query name, truncated at 200px | Yes (alphabetical) |
| Success Rate | `w-20` | "{n}/{window}" format (e.g., "8/10") | No |
| Last Success | `w-28` | Relative timestamp via `formatRelativeTime()` or "--" if never | Yes (oldest first default) |
| Consecutive Fails | `w-16` | Integer count, "0" when healthy | No |
| Last Error | auto | Error type string or "--" when no error | No |

Sort indicator: Use `text-foreground` on active column header, `text-muted-foreground` on inactive. Append ascending/descending arrow icon from lucide (`ArrowUp`, `ArrowDown`).

### QueryCard Mini-Dots (UrlHealthDots)

Position: After the StatusDot line (line 170-177 in current QueryCard), before the schedule line (line 179).

```
  (existing) ● OK  2 hours ago
  (new)      ● amazon.com
  (new)      ● bestbuy.com
  (new)      ● walmart.com
  (existing) Clock icon · Every 6 hours · next in 4h
```

- Each mini-dot row: `h-2 w-2` dot + `gap-1.5` + domain label in `text-xs text-muted-foreground`
- Container: `mt-2 flex flex-col gap-1` wrapping all mini-dot rows
- Tooltip on each row: `"{domain} · {success_count}/{window} · last success {relative_time}"`
- Tooltip implementation: shadcn `Tooltip` component (already available in ui/) or native `title` attribute. Use `title` attribute for simplicity -- no additional shadcn component install needed.

### Header Navigation

Add "Health" text link in the header between the logo and the right-side controls:

```
| Price Scraper     Health     [ThemeToggle] [Bell] |
```

- Link style: `text-sm font-medium text-muted-foreground hover:text-foreground transition-colors`
- Active state (on `/health` route): `text-foreground`
- Implementation: Use React Router `NavLink` component with `className` callback

## Interaction States

### Health Table

| State | Behavior |
|-------|----------|
| Loading | 5 skeleton rows (match AlertsPage `SkeletonRows` pattern) |
| Empty | `EmptyState` with heading "No URLs tracked" and body "Add retailer URLs to your watch queries to see their health status here." |
| Error | `ErrorState` with default message |
| Populated | Full table with all retailer URLs |
| Sort click | Toggle sort direction on sortable columns. Active column header shows arrow icon. |
| Filter click | Toggle between "All" and "Degraded & Failing". Active filter uses `variant="default"`, inactive uses `variant="outline"`. |
| Row hover | `hover:bg-accent` (matches AlertsPage table row pattern) |
| Row click | No action (read-only per D-11) |

### QueryCard Mini-Dots

| State | Behavior |
|-------|----------|
| Loading (detail fetching) | Do not render mini-dots section (same as existing price skeleton behavior) |
| No health data yet | Do not render mini-dots section |
| Health data available | Render one dot per retailer URL |
| Hover on dot row | Show `title` tooltip with health details |
