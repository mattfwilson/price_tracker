## Layout Contract

### WaybackStats Row Structure

The stats row appears directly below the existing price/delta/badge line inside ListingRow, within the `min-w-0 flex-1` container.

```
<ListingRow>
  <div py-3 flex items-center justify-between>
    <div min-w-0 flex-1>
      <p truncate font-medium text-sm>       {product_name}
      <div mt-1 flex items-center gap-2>     {price} {delta} {[Lowest]}
      <div mt-1 flex flex-wrap items-center gap-x-2 text-xs text-muted-foreground>
        {30d: $51.99 (Mar 12)}  {separator}
        {90d: $53.49 (Dec 23)}  {separator}
        {avg $50.12 (18 pts)}   {DealBadge}
      </div>
      <div mt-1 flex items-center gap-x-2 text-xs text-muted-foreground>
        {Low: $42.00}  {separator}  {High: $67.99}
      </div>
    </div>
    <button>View history</button>
  </div>
</ListingRow>
```

### Stats Row Rendering Rules

| Condition | Behavior |
|-----------|----------|
| No scrape results at all (`latest_result` is null) | Entire WaybackStats row hidden (existing "No scrape data yet" remains) |
| No 30d price found (null) | Omit the "30d: ..." segment; do not show placeholder |
| No 90d price found (null) | Omit the "90d: ..." segment; do not show placeholder |
| 30d avg count < 3 | Omit the 30d average segment |
| 90d avg count < 3 | Omit the 90d average segment AND suppress DealBadge |
| 90d avg available but count >= 3, current price < avg | Show green "Good deal" badge |
| 90d avg available but count >= 3, current price >= avg | Show red "Above avg" badge |
| All wayback fields null | Entire WaybackStats row hidden (returns null) |
| All-time low/high both null | Omit the all-time extremes sub-row |
| All-time low equals all-time high (single data point) | Show both (they represent the same value; user sees the data is sparse) |

Source: D-01, D-03, D-05 from CONTEXT.md.

| Property | Value | Tailwind |

### Loading Skeleton

When the detail endpoint is loading (TanStack Query `isLoading`), render a skeleton placeholder for the stats row:

```
<Skeleton className="mt-1 h-4 w-64" />
```

Single skeleton bar, 16px tall (`h-4`), 256px wide (`w-64`), positioned with `mt-1` to match the stats row placement. This is consistent with the Skeleton component already in the project.

## Interaction States

| State | Visual Treatment |
|-------|-----------------|
| Detail loading | Skeleton bar (`h-4 w-64`) below price line |
| Detail loaded, all wayback fields present | Full stats row with all segments + deal badge + all-time extremes |
| Detail loaded, partial wayback data | Only populated segments shown; missing segments omitted |
| Detail loaded, no wayback data at all | Stats row not rendered; ListingRow looks identical to pre-Phase-9 |
| Dark mode | All colors use Tailwind opacity modifiers (emerald-500/15, red-500/15) which render correctly in both themes; text uses `text-muted-foreground` which adapts via CSS variables |

## Accessibility

| Concern | Implementation |
|---------|----------------|
| Color contrast | Badge text (emerald-400, red-400) on transparent backgrounds meets WCAG AA for large text (12px bold equivalent in Badge); muted-foreground on background meets AA |
| Screen reader | DealBadge content ("Good deal" / "Above avg") is plain text, readable by screen readers. No aria-label needed since the Badge contains visible text |
| Keyboard | No new interactive elements. Existing "View history" button remains the only focusable element in ListingRow |
