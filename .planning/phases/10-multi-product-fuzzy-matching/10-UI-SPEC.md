### Header Nav Addition

Add between "Health" NavLink and the right-side controls:

```tsx
<NavLink to="/matches" className={...same pattern as Health...}>
  Matches
  {pendingCount > 0 && (
    <span className="ml-1.5 inline-flex h-5 min-w-[20px] items-center justify-center rounded-full bg-primary text-primary-foreground text-xs font-bold px-1">
      {pendingCount}
    </span>

```

Badge uses `bg-primary` (blue) to differentiate from the alert bell's `bg-destructive` (red). Pending suggestions are informational, not urgent.

## Interaction Contracts

### Confirm Match Suggestion
1. User clicks "Confirm" on SuggestionCard
2. Button shows loading spinner (Button disabled, isPending state)
3. POST /api/matches/confirm with member IDs
4. On success: card animates out (or page refetches), confirmed group appears in lower section
5. On error: sonner toast with error message, button re-enables

### Reject Match Suggestion
1. User clicks "Reject" on SuggestionCard
2. Button shows loading spinner
3. POST /api/matches/reject with pair IDs
4. On success: card animates out (or page refetches)
5. On error: sonner toast with error message

### Unmatch Confirmed Group
1. User clicks "Unmatch" on ConfirmedGroupCard
2. AlertDialog opens with confirmation copy
3. User clicks "Unmatch" in dialog
4. Dialog shows loading state
5. DELETE /api/matches/groups/{id}
6. On success: dialog closes, card removed, all member pairs added to rejected_pairs
7. On error: sonner toast with error message

### View History (from confirmed group)
1. User clicks "View history" link on a member column
2. Navigate to existing query detail view with the relevant listing's price history expanded
3. Uses existing router navigation (react-router-dom Link)
